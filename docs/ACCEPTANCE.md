## 二、环境准备

### 1. 启动前端（默认 Mock）

```bash
cd frontend
npm install
npm run dev
```

浏览器打开 **http://localhost:5173**。Mock 模式内置 20 条演示数据，**刷新页面即重置**。

### 2. 切换真实后端

```bash
# frontend/.env.local
VITE_USE_MOCK=false
```

启动 Flask 后端（`http://127.0.0.1:5000`），重启 `npm run dev`；Vite 会把 `/api/v1` 代理到 5000 端口。

### 3. 生产构建

```bash
cd frontend
npm run build      # 产物 dist/，含 dist/templates/contacts-import-template.xlsx
npm run preview    # 可选：本地预览构建产物
```

### 4. 验收数据

- 导入模板（应用内下载或 `frontend/public/templates/contacts-import-template.xlsx`）
- 导入样例：[docs/acceptance/import-sample.xlsx](acceptance/import-sample.xlsx)
  - 共 4 行：李雷、韩梅梅为合法行；第 3 行姓名为空、第 4 行邮箱非法，用于验证失败明细。
  - 真实后端预期：总行数 4、成功 2、失败 2（以实际后端逐行解析为准）。
  - Mock 模式不解析文件内容，固定返回 10 行 / 8 成功 / 2 失败。

### 4.7 快捷键、可访问性与字段错误

| 验收项 | 操作 | 预期 |
| :--- | :--- | :--- |
| 搜索快捷键 | `Ctrl / ⌘ K` | 搜索框获得焦点；Mac 显示 `⌘K`，Windows 显示 `Ctrl K` |
| 行键盘操作 | Tab 到行 → Enter | 打开该行详情（1280 面板 / 窄屏抽屉） |
| 抽屉焦点 | 抽屉打开后按 Tab | 焦点在抽屉内循环，不跑到背后的列表 |
| 语义属性 | DevTools 查看 | 行 `tabindex=0`、`aria-label="查看 X 的详情"`、选中行 `aria-current=true`；表头 `aria-sort`；抽屉 `role=dialog` / `aria-modal` |
| 骨架屏 | 刷新页面 | 首次加载显示骨架，`aria-busy`；已有数据翻页不闪骨架 |
| 减少动效 | 系统开启「减少动态效果」 | 骨架屏不做呼吸动画 |

**方法 A：真实后端字段错误**

```bash
curl -X POST http://127.0.0.1:5000/api/v1/contacts \
  -H "Content-Type: application/json" \
  -d '{"name":"","phones":[{"label":"手机","number":"abc","is_primary":true}],"emails":[{"label":"个人","email":"bad@","is_primary":true}]}'
```

确认返回 `details`。随后在页面里制造同类错误（若前端已拦截，可临时用 DevTools 方法 B 验证 UI 映射）。

**方法 B：仅验证前端 UI 映射（无需后端）**

打开「编辑联系人」弹窗，在 DevTools Console 执行：

```js
(() => {
  const el = document.querySelector('.contact-dialog')
  let inst = el && el.__vueParentComponent
  while (inst) {
    if (inst.type.__name === 'ContactFormDialog') {
      inst.props.serverErrors = {
        name: ['姓名已存在，请使用其他姓名'],
        phones: ['第 1 项电话号码格式不合法', '第 2 项电话号码格式不合法'],
        emails: ['第 1 项邮箱已被占用']
      }
      return '已注入'
    }
    inst = inst.parent
  }
  return '未找到弹窗'
})()
```

预期：姓名下方错误；电话分区显示两条错误并同时红框两行；邮箱分区一条错误。修改任一字段后错误清除。

## 五、契约与 Mock 差异

| 能力 | 真实后端 | Mock |
| :--- | :--- | :--- |
| 列表 / 详情 / 增删改 / 收藏 | 按 [API.md](API.md) | 同结构，内存数据，刷新重置 |
| 导入 | 真实解析 `.xlsx` 并逐行写入 | 不解析内容，固定 10/8/2 并追加 8 条演示联系人 |
| 导出 | 返回 `.xlsx` 二进制 | 返回 8 列 CSV 演示文件，最多 100 条 |
| 分组计数 | 前端以 `page_size=100` 聚合 | 同左，20 条数据完整 |

## 六、已知限制

1. 375px 手机端未适配（本次范围外），768 以下按最小宽度横向滚动。
2. Mock 导入不解析文件内容，失败明细为固定演示数据。
3. 真实后端字段级错误仅完成前端映射与注入验证，需与后端联调确认 `details` 文案。
4. 分组计数在联系人超过 100 条时可能不完整（契约无分组统计接口）。
5. 姓名排序仅当前页（契约无排序参数）。
6. 删除后不会自动清理浏览器下载目录中的导出文件。
